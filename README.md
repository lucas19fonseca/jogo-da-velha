# Jogo da Velha com IA (Minimax)

## Descrição

Este projeto é um protótipo simples de um Jogo da Velha (tic-tac-toe) jogado contra uma Inteligência Artificial que utiliza o algoritmo *Minimax* para tomar decisões ótimas.

A IA analisa todas as jogadas possíveis, simulando o resultado de cada uma, e escolhe o movimento que maximiza suas chances de vitória ou empate.

---

## Como funciona

- O jogador humano joga com *X*.
- A IA joga com *O*.
- O tabuleiro é exibido no console.
- O jogador insere a posição (linha e coluna de 0 a 2) para fazer sua jogada.
- A IA responde imediatamente com sua melhor jogada.
- O jogo termina quando alguém vence ou dá empate.

---
